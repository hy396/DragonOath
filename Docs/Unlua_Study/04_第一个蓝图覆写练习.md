# 04 第一个 UnLua 练习：覆写 Actor 生命周期

本练习目标：让场景中的 `BP_UnLuaHello` 在开始运行和 Tick 时输出 Lua 日志。它只验证“蓝图绑定 -> Lua 模块加载 -> 事件覆写”这条链路，不修改任何游戏逻辑。

## 1. 创建 Lua 文件

在资源管理器或 IDE 中创建：

```text
Plugins/UnLua/Content/Script/Tutorial/HelloUnLua.lua
```

写入：

```lua
local HelloUnLua = UnLua.Class()

function HelloUnLua:ReceiveBeginPlay()
    print("[UnLuaTutorial] ReceiveBeginPlay: Lua module is running")
    self.elapsed_seconds = 0.0
end

function HelloUnLua:ReceiveTick(delta_seconds)
    self.elapsed_seconds = self.elapsed_seconds + delta_seconds

    if self.elapsed_seconds >= 2.0 then
        print("[UnLuaTutorial] Two seconds passed")
        self.elapsed_seconds = 0.0
    end
end

return HelloUnLua
```

`UnLua.Class()` 创建供 UE 绑定的 Lua 类表。`ReceiveBeginPlay` 和 `ReceiveTick` 是 Actor 蓝图可覆写事件的 Lua 版本。不要把 `print` 放到每帧无条件执行，日志会迅速淹没真正的问题，因此示例每两秒才输出一次。

## 2. 在蓝图中绑定模块

打开 `/Game/UnLuaTutorial/BP_UnLuaHello`，使用 UnLua 提供的蓝图绑定入口将模块设置为：

```text
Tutorial.HelloUnLua
```

不同 UnLua 版本的编辑器 UI 文字可能略有不同，常见入口是蓝图的 **Class Settings** 或 UnLua 分类中的 **Module Name**。应填模块路径，不填文件系统绝对路径，也不写 `.lua` 扩展名。

把这个 Actor 拖入一个测试关卡，Play in Editor。

## 3. 验收

在 Output Log 中筛选 `UnLuaTutorial`，应依次看到：

```text
[UnLuaTutorial] ReceiveBeginPlay: Lua module is running
[UnLuaTutorial] Two seconds passed
```

看到第一条，说明模块路径、Lua 文件语法和蓝图绑定正确；持续看到第二条，说明 Tick 覆写也成功。

## 4. 常见失败排查

| 现象 | 优先检查 |
| --- | --- |
| 没有任何日志 | 蓝图是否已放入当前关卡；模块名是否为 `Tutorial.HelloUnLua`；UnLua 是否启用 |
| `module not found` | 文件是否在 `Plugins/UnLua/Content/Script/Tutorial/HelloUnLua.lua`；模块名不能含 `.lua` |
| Lua 语法报错 | 每个 `function`、`if` 都要有匹配的 `end`；字符串引号必须成对 |
| `attempt to index a nil value` | 变量/表字段尚未创建，或拼错名称；先在使用前初始化 |
| Tick 不执行 | 检查 Actor 是否允许 Tick；先用 `ReceiveBeginPlay` 确认加载链路 |

## 5. 小作业

给蓝图增加一个 `Float` 类型、可编辑实例变量 `LogInterval`，然后在 Lua 中读取它替换硬编码的 `2.0`。为避免未配置时出错，Lua 应在变量为 `nil` 或小于等于零时使用 `2.0`。

提示：Lua 中可按 `self.LogInterval` 访问暴露给蓝图的属性；这是 UE 反射映射，不是 Lua table 自己声明的字段。

参考实现：

```lua
function HelloUnLua:ReceiveBeginPlay()
    self.elapsed_seconds = 0.0
    self.log_interval = self.LogInterval
    if self.log_interval == nil or self.log_interval <= 0.0 then
        self.log_interval = 2.0
    end
end
```
