# 08. 2.5D Depth Movement Design

## 1. 方案结论

DragonOath 的 2.5D 角色移动采用“X 轴主战斗移动 + Y 轴有限纵深走位”的方式。

```text
X 轴：A/D 左右移动，承担主要战斗节奏
Y 轴：W/S 前后移动，用于调整站位、躲避和近战对齐
Z 轴：跳跃、浮空、击飞和落地
```

纵深移动速度默认低于横向移动速度。第一阶段不拆分 CharacterMovement 的基础移动速度，而是保留一个 `MaxWalkSpeed`，通过 `DepthMoveScale` 对 Y 轴输入进行倍率调整。

## 2. 摄像机俯角与速度关系

摄像机俯角为 8°～12° 时，Y 轴纵深移动投影到屏幕上的位移会明显小于 X 轴横向移动。以 10° 俯角为例：

```text
屏幕上的纵深位移 ≈ 世界 Y 位移 × sin(10°)
                  ≈ 世界 Y 位移 × 0.17
```

因此 W/S 即使和 A/D 使用相同的世界速度，视觉上也会显得更慢。但不建议为了补偿投影而把纵深速度提高到横向速度的 5～6 倍，这会导致角色在真实战斗空间中移动过快。

本方案暂定采用：

```text
CharacterMovement.MaxWalkSpeed = 600 cm/s
DepthMoveScale                 = 0.6

A/D 横向移动：约 600 cm/s
W/S 纵深移动：约 360 cm/s
```

`DepthMoveScale` 只影响输入强度，不改变摄像机俯角，也不改变 CharacterMovement 的网络移动流程。摄像机固定观察 Y 轴，不跟随角色的 Y 轴位置移动。

推荐调参范围：

| 参数 | 推荐范围 | 默认值 | 说明 |
|---|---:|---:|---|
| `MaxWalkSpeed` | 400～800 cm/s | 600 | 角色基础移动速度，使用 UE CharacterMovement 参数 |
| `DepthMoveScale` | 0.5～0.75 | 0.6 | W/S 相对于 A/D 的纵深移动倍率 |
| `DepthRange` | 300～600 cm | 按关卡配置 | 单个战斗区域允许的 Y 轴活动范围 |

最终倍率不以数学投影结果为准，而以近战命中、躲避、怪物围攻和多人站位的实际手感为准。

## 3. 蓝图可编辑参数

在 `ADOPlayerCharacter` 中增加可编辑属性：

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "DO|Movement", meta = (ClampMin = "0.0", ClampMax = "1.0", UIMin = "0.0", UIMax = "1.0"))
float DepthMoveScale = 0.6f;
```

属性规则：

- `EditAnywhere`：可以在角色蓝图默认值中编辑。
- `BlueprintReadWrite`：蓝图可以读取，也可以在运行时按需要修改。
- `ClampMin/ClampMax`：限制倍率在 0～1 之间。
- `DO|Movement`：移动参数统一放在该蓝图分类下。

基础横向速度继续使用 UE 自带的：

```cpp
GetCharacterMovement()->MaxWalkSpeed
```

该参数可以直接在角色蓝图的 `CharacterMovement` 组件中编辑。第一版不额外创建重复的 `HorizontalMoveSpeed` 属性，避免 C++ 参数和 CharacterMovement 参数出现两个来源。

后续如果不同职业、装备或状态需要完全不同的移动配置，再考虑将速度参数迁移到 `DA_MovementSettings` 或角色数据资产中。

## 4. 输入实现

当前项目的 `IA_Move` 为 `Axis2D`，约定为：

```text
Value.X -> A/D，世界 X 轴横向移动
Value.Y -> W/S，世界 Y 轴纵深移动
```

### 4.1 C++ 实现

`Input_Move` 的实现建议：

```cpp
void ADOPlayerCharacter::Input_Move(const FInputActionValue& InputActionValue)
{
    const FVector2D RawValue = InputActionValue.Get<FVector2D>();

    FVector2D MoveValue = RawValue;
    MoveValue.Y *= DepthMoveScale;

    // 避免斜向移动时总输入超过 1.0。
    if (MoveValue.SizeSquared() > 1.0f)
    {
        MoveValue.Normalize();
    }

    if (FMath::Abs(MoveValue.X) > KINDA_SMALL_NUMBER)
    {
        AddMovementInput(FVector::ForwardVector, MoveValue.X);

        // 角色转身只由横向输入决定。
        const float TargetYaw = MoveValue.X > 0.0f ? 0.0f : 180.0f;
        SetActorRotation(FRotator(0.0f, TargetYaw, 0.0f));
    }

    if (FMath::Abs(MoveValue.Y) > KINDA_SMALL_NUMBER)
    {
        AddMovementInput(FVector::RightVector, MoveValue.Y);
    }
}
```

`CharacterMovementComponent` 继续负责加速、减速、碰撞、客户端预测和服务器同步。不要使用客户端 `SetActorLocation` 代替正常移动。

### 4.2 蓝图验证

如果先用蓝图验证手感，不需要修改移动组件：

```text
IA_Move
  -> Break Vector2D

X
  -> Add Movement Input
  -> World Direction = Forward Vector

Y
  -> Float * DepthMoveScale
  -> Add Movement Input
  -> World Direction = Right Vector
```

角色转身仍然只读取 X：

```text
X > 0 -> Rotation Yaw = 0
X < 0 -> Rotation Yaw = 180
```

W/S 不改变角色左右朝向。

## 5. 纵深范围限制

每个战斗区域使用两个 Y 轴方向的阻挡体限制纵深：

```text
DepthMin 阻挡体
    [角色可活动区域]
DepthMax 阻挡体
```

第一阶段推荐纵深范围为 300～600 cm。阻挡体至少配置：

```text
Collision Enabled = Query and Physics
Pawn             = Block
```

使用关卡碰撞限制纵深，不使用客户端 `SetActorLocation` 强行 Clamp，避免破坏 `CharacterMovementComponent` 的移动预测和服务器同步。

冲刺、击飞和 Root Motion 技能也必须在测试房间中验证不会穿过纵深边界。若后续需要不同区域拥有不同深度，应通过区域配置或边界体切换规则管理，不要在角色蓝图里写死整张地图的范围。

## 6. 网络规则

纵深移动和横向移动都属于 CharacterMovement 的正常移动输入：

```text
客户端输入
  -> CharacterMovement 客户端预测
  -> 移动请求发送服务器
  -> 服务器验证并复制角色位置
  -> 客户端修正误差
```

`DepthMoveScale` 是本地角色移动配置，客户端和服务器使用相同的角色类默认值。服务器仍然是最终位置权威方。

不要把纵深位置通过 GameplayMessageRouter 同步，也不要在摄像机系统中修正角色位置。GameplayMessageRouter 只适合本地表现通知，不承载移动请求。

## 7. 调参验收

在固定俯角 10° 的测试房间中，至少验证：

- A/D 移动保持主要战斗节奏。
- W/S 移动明显慢于 A/D，但不会感觉迟钝。
- 蓝图修改 `DepthMoveScale` 后，W/S 速度立即符合预期。
- 斜向移动不会超过基础 `MaxWalkSpeed`。
- W/S 不改变角色左右朝向。
- 角色不会因为纵深移动离开战斗区域。
- 冲刺、击飞和 Root Motion 不会穿过纵深边界。
- Listen Server + Client 下移动预测、碰撞和位置同步正常。

## 8. 后续扩展

第一版只保留一个全局 `DepthMoveScale`。后续根据内容需求再考虑：

- 不同角色拥有不同的纵深移动倍率。
- 冲刺或特殊技能临时修改纵深移动倍率。
- 地形或区域限制不同的纵深范围。
- 通过 DataAsset 配置移动速度、纵深倍率和状态修正。
- 纵深移动动画、脚步音效和前后遮挡表现。
